# キキクルよみ（kikikuru-yomi）

架空の場面（場所・キキクルの種類・色）を見て、とる行動を当てる1日5問の学習ゲーム。正解したら、その色が警戒レベルいくつ相当か（2〜5）も選ぶ。キキクルの種類（土砂・浸水・洪水）と指数、警戒レベルの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/kikikuru-yomi/>

- 中身は気象庁の「キキクル（危険度分布）」<https://www.jma.go.jp/jma/kishou/know/bosai/riskmap.html> と「防災気象情報と警戒レベルとの対応について」<https://www.jma.go.jp/jma/kishou/know/bosai/alertlevel.html> に書いてあることだけです。
- 問題に出る場所や様子は練習のための例で、本物の大雨ではありません。
- このゲームは防災の助言や、公式の情報の代わりではありません。本当の大雨のときは、気象庁のキキクルと市町村の避難情報で確かめてください。
